## 还原了什么？

作者通过对CS2现有机制的了解，做出了一些非现有版本的改动，这些改动可能来源于前版本的机制。或对于Minecraft固有机制的权衡，做出了平衡性的改动。

### 0.准备地图
由于该数据包源于群友内战，所以没有任何匹配机制。
