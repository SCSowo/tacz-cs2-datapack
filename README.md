## 还原了什么？

作者除通过对CS2现有版本的机制进行还原之外，还做出了一些非现有版本的改动，这些改动可能来源于前版本的机制。或对于Minecraft固有机制的权衡，做出了平衡性的改动。

> 例如，在2026年3月19日，Valve对CS2的换弹机制进行了颠覆性的重构。多数武器从“近乎无限”备用弹药改为固定数量弹匣。换弹时，当前弹匣内所有未发射子弹直接作废。
> 
> 在该数据包中，由于技术所限和游戏习惯的权衡，换弹机制依旧采用tacz模组的默认机制（即和上述日期更新前机制相同）而非当前版本机制。


### 0.准备工作

为适应内战的多地图设置，数据包添加了地图槽位功能。

服务器管理者可以通过`/function cs2d:book`获得管理书，对地图进行管理。

### 1.选边和开始

由于该数据包源于群友内战，所以没有任何与原游戏相似的匹配机制。游戏开始前，服务器管理者可以通过管理书进行准备，并在玩家选择阵营后决定开启游戏。

### 2.竞技模式

游戏分为CT阵营和T阵营，CT阵营守护目标，T阵营爆破目标。

数据包采用MR13赛制，第12回合结束后，将采取换边。CT阵营和T阵营场地互换。

每回合开始时，所有玩家的第2格物品栏将获得对应阵营的默认手枪，CT阵营获得USP消音版，T阵营获得格洛克18型。

每回合开始时，T阵营将随机指定一名玩家的第8格物品栏获得C4炸弹。

第1回合开始时，所有玩家默认获得800$。

每回合中，所有玩家击杀敌方阵营玩家，根据枪械不同，可以获得不同程度的击杀奖励。

每回合中，T阵营成功在任意目标范围内安装C4炸弹，可以获得300$。

每回合中，当CT阵营玩家成功拆除C4炸弹，可以获得300$。

每回合结束，且敌方玩家均被击杀时，胜方可以获得3250$。时间耗尽时，CT阵营获得3250$，T阵营获得0$。当C4炸弹被拆除时，CT阵营获得3500$，当C4炸弹成功被引爆时，T阵营获得3500$，未能成功引爆并输掉比赛时，则T阵营再额外获得600$。
