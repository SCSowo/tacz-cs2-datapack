# CS2 主游戏流程

本数据包（命名空间 `cs2d`）已接入 TaCZ 真枪，按 CS2 竞技模式的数值与流程重写。依赖 forge 1.20.1 + TaCZ 1.1.8 + 绿葡萄战术装备（lrtactical）+ **4 套 TaCZ 枪包**（见 §一）。

> 地图/区域/多地图槽位那套没变，见 [`DEMO说明.md`](DEMO说明.md)。本文档只讲**武器、经济、回合、赛制**。

| 枪包命名空间 | 提供 | 备注 |
|---|---|---|
| `cs2_wt` | 10 把 + 爪刀 | CS2 Pack 枪与刀 / CS2 Knifes Pack（原作只有这 10 把） |

[`DEMO说明.md`](DEMO说明.md) 的「三之十三、枪械扩充」**。

备弹用 TaCZ 的 `DummyAmmo`（虚拟备弹）实现：不占背包、每回合随发枪重置，跟 CS2 的"每回合补满备弹"一致。

## 三、经济（CS2 官方数值）

| 项目 | 数值 |
|---|---|
| 起始资金 | $800 |
| 金钱上限 | **$16000**（每次入账后自动 clamp） |
| 回合胜利 | **+$3250** |
| 回合失败（连败阶梯） | 第 1 次 $1400 → 第 2 次 $1900 → 第 3 次 $2400 → 第 4 次 $2900 → 第 5 次及以后 **$3400** |
| 安放炸弹 | T 全员 **+$300** |
| 拆除炸弹 | 拆除者本人 **+$300** |
| T 输掉但本回合安放过炸弹 | T 全员额外 **+$800** |

连败计数存在 `#lossT` / `#lossCT`，赢一回合即清零。

**装备在回合之间保留**（存活者不用重买），**死亡后全部丢失**（`death.mcfunction` 里清零并重发）——和 CS2 一致。

## 四、回合与赛制

| 项目 | CS2 数值 | 本包 |
|---|---|---|
| 购买时间（冻结） | 15 秒 | 15 秒 |
| 回合时长 | 1:55 | **115 秒** |
| 回合结算 | — | 5 秒 |
| C4 倒计时 | 40 秒 | **40 秒** |
| 安放耗时 | 约 4 秒 | **65 tick = 3.25 秒**，常量 `#plantt` |
| 拆除耗时 | 10 秒 / 有钳 5 秒 | 无钳 **200 tick（10 秒）** / 有钳 **100 tick（5 秒）** |
| 赛制 | MR12 | 先到 **13** 分 |
| 半场 | 12 回合后换边 | 第 13 回合开始前自动换边 |
| 加时 | MR3 | 12:12 触发，先到 **16** 分，双方 $10000 |

半场换边**只换玩家的队伍**，并交换 T/CT 的比分、重置经济（常规赛回 $800、加时 $10000）、清零连败阶梯与阵营限定物品（拆弹钳、手枪按新阵营重发）。

> ⚠️ **地图不动**（2026-09-26 修复）：CS2 里出生点和包点都是**地图固定**的，换边后 T 从「地图上的 T 出生点」出发，
> 而不是从「上半场 CT 的出生点」出发。所以 `swap_sides` **不交换区域坐标、也不交换出生点 marker**。
> 早期版本把「区域坐标 + marker + 队伍」三样一起换，交换是对合运算、换两次 = 没换，
> 结果双方都还站在原地、高光方位也是反的。**已换过边的存档部署新包后执行一次 `/function cs2d:map/unswap` 复原。**

## 五、装备槽位（快捷栏映射）

```
0=主武器  1=手枪  2=刀  3=闪光弹  4=HE  5=烟雾  6=燃烧瓶  7=C4(固定)  8=(空)
                                                          拆弹钳不再给物品，走 cs2d.kit 记分板
```

**C4 固定发在第 8 格**（`hotbar.7` + NBT 标记 `cs2d_s:7b`）：买枪走 `item replace hotbar.0`，只碰第 1 格，谁都动不了 C4（以前用 `give`，会落到第一个空槽，买枪时正好被顶掉 —— 就是这个"吞 C4"）。
投掷物因此整体顺移一格；拆弹钳改成纯记分板记录（背包 27 格禁止放东西，没地方放物品）。

C4 每回合随机发给一名 T。**安放：站在包点里按住潜行（Shift）3.25 秒**（移动 / 松开 / 离开包点 / 死亡都会中断，中断后重新蹲满）。
`/trigger cs2d.plant set 1` 现在只做条件自检，不再直接下包。

**死亡后**：`gamerule doImmediateRespawn true` 会把人瞬间丢到重生点，所以 `spawn_home` 在死亡 / 回合开始 / 选队 / 读档四个时机把人送回本阵营出生点并写死 `spawnpoint`；`respawn_guard` 兜底抓「标记死亡却不是旁观」的情况。

## 六、表现层

- **killfeed**：击杀时全服广播 `凶手 「武器名」 死者`，凶器通过读取手上物品的 `GunId` / `MeleeWeaponId` 判定，刀杀额外显示 🔪
- **MVP**：每回合结算时评选本回合击杀最多者，+1 MVP 并公告
- **回合横幅**：区分「炸弹爆炸 / 炸弹被拆除 / 时间到 / 歼灭」四种结束原因，显示比分
- **HUD**（actionbar）：只显示 `$金钱`（血量用原版血条、护甲用原版护甲条，都不重复）
- **安放 / 拆除进度**：bossbar `cs2d:plant`（max 65）与 `cs2d:defuse`（max 随有没有钳子切 100 / 200）
- **购买菜单 = 聊天栏按钮**：`cs2d:buy_menu` 按阵营分发到 `buy/chat_t` / `buy/chat_ct`，
  回合开始时自动推 6 行（主武器 / 手枪 / 投掷 / 装备 / 退款 / 重看菜单，码 99 = 退款、98 = 重发菜单）。
  **成书方案已废弃**（1.20.1 没法用命令打开书 GUI，还占格子会被买枪顶掉）。
- **购买窗口**：冻结期（15s）全程 + 开局后 `#buywin` 秒（默认 20）内仍可买；actionbar 显示 `购买时间 Ns   $金钱`。
- **退款**：每次购买记录 `cs2d.lb`（商品码）+ `cs2d.lbp`（实付金额），窗口内可退最近一次，全额返还、
  封顶 $16000；回合开始时归零。护甲按实付退（头盔 $350 / 整套 $1000），手枪退回默认（T→Glock、CT→USP）。
- **防重复购买**：已持有同款武器 / 投掷物达上限 / 已有护甲钳 → 拒绝并提示，不重复扣钱。
- **顶栏 bossbar `cs2d:info`**：`T □□□ 3   1:42   5 □□□□ CT`
  —— **□ 的数量 = 该队存活人数**（最多 5 个），紧挨着的数字 = 本队回合比分，中间是倒计时。
  方块串存在 `cs2d:bar` 的 `tb` / `cb`，bossbar name 用 `{"nbt":...}` 组件渲染
  （1.20.1 不能按分数重复字符串，只能按人数覆盖赋值六次）。
  **右侧计分板已停用**（`load` 里 `scoreboard objectives setdisplay sidebar` 清空显示槽），
  `cs2d:info` 常驻显示：未开赛 `CS2 竞技 0 : 0`、已停止 `已停止 x : y`。
- **C4 滴答**：`bomb_beep` 每 tick 递减 `#beep`，到点就响一声并按下一段间隔重置 ——
  剩 20s 以上每 1 秒、20~11s 每 0.5 秒、10~6s 每 0.25 秒、最后 5 秒每 0.15 秒，音调也逐段升高。
- **爆炸范围**（按 CS2 近期那次扩大调整）：**12 格内必死**，12~20 格瞬间伤害 IV（满血只剩 8 血）。
  想再改就调 `bomb_explode.mcfunction` 里的两个 `distance=`。

## 七、命令速查

```
/function cs2d:book          # 地图管理书（标区域 / 存读地图 / 第⑥页开局）
/function cs2d:team          # 选队书（T 橙 / CT 蓝，进服自动发一本，丢了自动补）
/function cs2d:buy_menu      # 购买菜单（回合冻结时自动发，也可手动拿）
/function cs2d:start         # 开始比赛（= 管理书第⑥页「开始比赛」）
/function cs2d:stop          # 强制停止
/function cs2d:diag          # 自检（含"谁带 C4"和安放耗时）
/function cs2d:bomb_plant    # 下包自检：逐条报出为什么不能安放（下包本身靠蹲下）
```

**下包 / 拆弹**

| 动作 | 操作 |
|---|---|
| 安放 C4 | 站在包点内 **按住潜行（Shift）3.25 秒**；移动或松开即中断（CS2 是按住使用键） |
| 拆除 C4 | 走到炸弹 3 格内 **按住潜行**：有钳 5 秒、无钳 10 秒；离开或松开即中断 |
| 自检 | `/trigger cs2d.plant set 1` / `/trigger cs2d.defl set 1` 只报「卡在哪一条」，不再直接执行 |

开局流程：玩家进服 → 选队书自选 T / CT → 管理员在管理书第⑥页点 **[ 开始比赛 ]**
（未选阵营的人会被自动补进人少的一方；比赛结束后停在这里等再次点开始，不会自动重开）。

调参：

| 想改什么 | 命令 |
|---|---|
| 胜利回合数 | `/scoreboard players set #target cs2d.g 13` |
| 起始资金 | 改 `match_start.mcfunction` 里的 `cs2d.money 800` |
| 冻结时长 | `round_start.mcfunction` 里 `#timer 15` |
| 回合时长 | `round_live.mcfunction` 里 `#timer 115` |
| 炸弹倒计时 | `bomb_planted.mcfunction` 里 `#bomb 40` |

| 护甲减伤 | `kit/apply.mcfunction` 里 `cs2d_kevlar 8` / `cs2d_helmet 4` |

## 八、已知限制

1. **无法判定爆头**。TaCZ 内部处理爆头伤害，数据包拿不到这个标记，killfeed 里不显示 `HS`。要做得改枪包或上 KubeJS。
2. **AWP 备弹 30 / 弹匣 5** 按枪包走（CS2 是 10/5，因为 CS2 的 AWP 弹匣是 10）。同理 M4A4 弹匣是枪包的 25 而非 CS2 的 30。
3. **扩充枪的击杀奖励与 killfeed 名是「其它」**。只有最早那 10 把枪 + 爪刀在 `kill/` 下单独配了奖励和显示名（$300~$1500），后续 22 把一律走 `kill/other`：**+$300、killfeed 显示「其它」**。补法见 §二 末尾的说明。
4. **不能捡地上的枪**。CS2 里可以捡尸体武器，这里没实现（C4 例外，掉落有专门接管逻辑）。
5. **killfeed 在聊天栏**。Minecraft 数据包的右上角 killfeed 要靠死亡消息，而死亡消息的文案在资源包里，数据包改不了。
6. 击杀检测依赖 `player_killed_entity` 进度，TaCZ 子弹伤害理论上能触发，但**这一步没实测过**。
7. **队友 X 光对敌方同样可见**。`glowing` 是实体状态位，原版没有「只对本队渲染轮廓」的接口。不想要就 `/trigger cs2d.ctrl set 97` 关掉。
8. **顶栏最多显示 5 个存活方块**，服务器超过 5 人时第 6 人起不再增加方块数（数字不受影响）。
