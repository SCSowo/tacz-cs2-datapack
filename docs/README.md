## 关于这两份文档的性质

`CS2主流程.md` 与 `DEMO说明.md` 是从实际运营的服务器上带出来的**原始开发文档**，
按时间顺序累积，因此：

1. **`DEMO说明.md` 后段的「三之N」章节是最新的**，与当前代码一致；
   前段（第一～五章）是早期版本，部分内容已被后续章节取代。
2. **两份文档冲突时，以 `DEMO说明.md` 靠后的章节为准。**
   已核对并修正过 `CS2主流程.md` 中与代码直接矛盾的数值（安放耗时、C4 槽位、枪械数量）。
3. 文中提到的 **`gen_fix*.py` / `gen_team*.py` / `gen_polish.py` 等一次性 patch 生成器
   没有随公开仓库发布** —— 它们的改动早已全部应用在 `data/` 里，只作变更记录阅读即可。
   同理，`_bak_before_*/` 是当时的改前备份，也不在仓库中。
4. 文中出现过的人名、服务器路径、IP 均已做脱敏替换。

## 校验脚本

```bash
python tools/validate.py            # 校验仓库根的数据包
python tools/validate.py <目录>      # 校验指定数据包目录
```

改完 `.mcfunction` 或战利品表**一定要跑一遍**：Minecraft 的函数文件一旦有一行解析失败，
整个函数会被**静默剔除**（执行时报「未知函数」，或在 tick 里毫无反应），
日志里才看得到 `Failed to load function`。该脚本把已知的坑全部做成了静态检查。
